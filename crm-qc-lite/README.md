# QC Lite — نسخه فشرده و فقط‌خواندنی

یک رابط سبک‌تر برای مرور سریع ارزیابی‌ها، وضعیت تیم و کارشناسان. این پروژه در پوشه‌ی مستقل `crm-qc-lite/` قرار دارد و از داده‌های مرجع همین ریپو **فقط خواندن** می‌کند؛ فایل‌های Excel/JSON و سامانه‌ی اصلی را تغییر نمی‌دهد.

## راه‌اندازی

از ریشه‌ی ریپو:

```bash
cd crm-qc-lite
npm start
```

سپس آدرس چاپ‌شده در ترمینال را باز کنید (پورت پیش‌فرض `8001` است؛ با `PORT=9000 npm start` می‌توان آن را عوض کرد).

## چه چیزی نمایش داده می‌شود؟

- فهرست ۶۵ کارشناس از `crm-qc/data/seed.json`
- ریت تماس MLM از `crm-qc/data/seed-calls/qc_mlm_form_2026-09-26.xlsx`
- ریت تماس اکانت از `qc_acc_form_2026-10-14T19_30_41.611923442+03_30.xlsx`
- فایل‌های تیکت و سوشال برای تشخیص وضعیت قالب/ردیف‌های ناقص؛ ردیف ناقص وارد آمار نمی‌شود.
- فیلتر تیم و ماه، مرور ریت‌ها، جزئیات معیارها، جست‌وجوی کارشناسان، خلاصه‌ی عملکرد و خروجی CSV محلی.

فایل‌های ریت تماس با همان پارسر مشترک `crm-qc/shared/parseQc.js` خوانده می‌شوند. نمره‌ها دوباره محاسبه نمی‌شوند. فیلدهای نام و شماره‌ی شریک از رابط و خروجی CSV حذف شده‌اند.

## تضمین عدم تغییر داده

- API این برنامه فقط `GET` و `HEAD` می‌پذیرد؛ درخواست‌های تغییردهنده با `405` رد می‌شوند.
- هیچ endpoint برای آپلود، ویرایش، حذف یا ذخیره‌ی محلی وجود ندارد.
- فیلترها فقط در حافظه‌ی همان صفحه‌اند و بعد از بستن صفحه ذخیره نمی‌شوند.
- برای کنترل این رفتار، `npm test` تعداد رکوردهای شناخته‌شده، فقط‌خواندنی‌بودن API و ثابت‌ماندن checksum فایل‌های مرجع را بررسی می‌کند.

## نیازمندی‌ها

Node.js نسخه‌ی ۱۸ یا جدیدتر. وابستگی جداگانه نصب نمی‌شود؛ پارسر Excel و موتور تاریخ از فایل‌های محلی همین ریپو استفاده می‌شوند.

> این پوشه یک پروژه‌ی جدا از نظر اجرا و رابط کاربری است، اما عمداً داده‌ها و کتابخانه‌های مرجع را کپی نمی‌کند. اگر روزی آن را به ریپوی مستقل منتقل کردید، باید مسیر/مجوز دسترسی به همین فایل‌های منبع را جداگانه تنظیم کنید؛ اصل فایل‌های داده را ویرایش یا بازتولید نکنید.
