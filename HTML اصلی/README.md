# سامانه کنترل کیفیت CRM — نسخه مستقل HTML

**فایل زیپ این فولدر را دانلود کنید → آن‌زیپ → `index.html` را دابل‌کلیک کنید. تمام.**

## بخش‌ها
| بخش | توضیح |
|---|---|
| داشبورد | شاخص‌های زنده + نمودار توزیع نمره و SLA |
| ارزیابی تیکت | ۴ المان + ردلاین — دقیقاً فرمول اکسل (۴۰/۲۰/۲۰/۲۰) |
| ارزیابی سوشال | مدت پاسخ‌گویی در ساعات کاری + SLA — فرمول اکسل (۳۰/۳۰/۲۵/۱۵) |
| گزارش‌ها | Agent Report / Team Report + **تب تجمیعی** (تیکت+سوشال+تماس یکجا) |
| **پرونده کارشناس** | جستجو با **نام یا داخلی** — همه دیتای تیکت/سوشال/تماس + نمودار روند ماهانه + اکسل چند‌سیتی |
| فیدبک تماس | پنل اصلی پروژه — دست‌نخورده در iframe |
| مدیریت پایه | کارشناسان، QCها، تنظیمات فرمول، بک‌اپ/بازیابی/ریست، **ایمپورت دیتای فیدبک تماس** |

## ماه مالی
در گزارش‌ها و پرونده کارشناس، انتخاب‌گر **«ماه مالی»** (از خرداد گذشته تا چند ماه آینده) به‌جای ورود دستی از/تا تاریخ، به‌صورت خودکار اول تا آخر ماه شمسی را اعمال می‌کند.

## پرونده کارشناس
- جستجو با تایپ نام **یا** شماره داخلی — پیشنهاد زنده
- خلاصه کارت شناسنامه + سه KPI (تیکت، سوشال، تماس) با میانگین‌ها
- **نمودار خطی روند ماهانه** نمره‌ها به تفکیک منبع
- سه جدول جمع‌بندی (تیکت، سوشال، تماس) + لیست توافق/اقدام و تعداد ویس‌ها
- خروجی **اکسل چند‌سیتی** (خلاصه، تیکت‌ها، سوشال، فیدبک تماس، توافقات)

## ایمپورت دیتای فیدبک تماس
پنل فیدبک قدیمی دیتای خود را روی دیسک (فایل `qc_recovery.json`) نگه می‌دارد. در «مدیریت پایه → دیتای فیدبک تماس» این فایل را ایمپورت کنید تا:
- در گزارش «تجمیعی» ستون تماس اضافه شود
- در «پرونده کارشناس» فیدبک‌های تماس، توافق و شمار ویس‌ها نمایش داده شود

با پاک کردن دیتای ایمپورتی، پرونده‌ها و گزارش‌ها به‌حالت قبلی برمی‌گردند.

## فیلدهای فنی
- دیتا: localStorage مرورگر (با دکمه بک‌اپ/بازیابی در مدیریت پایه)
- موتور محاسبات: `calc.js` + `reports.js` با نسخه سروری **مشترک و یکسان** — تست با دیتای اکسل مرجع
- تاریخ: جلالی fourmilab (تست‌شده روی اکسل DATA) — فروردین تا اسفند، کبیسه دقیق
