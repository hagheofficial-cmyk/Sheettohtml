# پوشه دیتای تماس — اتصال مستقیم اکسل‌های QC به سامانه

فایل‌های فرم QC تیم‌های تلفنی (tele)، اکانت (account) و MLM را **اینجا** بریزید.
سامانه به‌طور خودکار هر ۱۵ ثانیه این پوشه را بازبینی و دیتاهای جدید را به **همه** گزارش‌ها
(داشبورد، پرونده کارشناسان، گزارش ترکیبی) می‌آورد.

## نام‌گذاری (پیشنهادی — اجباری نیست)
- `qc_tele_*.xlsx` → فرم تماس تیم تلفنی
- `qc_account_*.xlsx` → فرم اکانت
- `qc_mlm_*.xlsx` → فرم MLM/BNPL
- `qc_recovery.json` → فایل بازیابی صادرشده‌ی پنل فیدبک (اختیاری)

> اگر نام فایل «گویا» نباشد (مثلاً `گزارش شهریور.xlsx`)، سامانه از **محتوای ستون‌ها**
> نوع فرم را خودش تشخیص می‌دهد.

## رفتار سینک
- **افزوده‌شدن فایل جدید** → ردیف‌هایش خوانده و به دیتای فیدبک تماس اضافه می‌شود.
- **تغییر فایل** (بازنویسی/ویرایش) → ردیف‌های نسخه قبلی همان فایل پاک و نسخه جدید جایگزین می‌شود.
- **حذف دستی ردیف‌های یک فایل** → در صفحه فیدبک، کارت «پوشه اکسل‌های فیدبک» → پاک‌سازی.
- گزارش‌های داخل سامانه (پرونده، داشبورد، گزارش ترکیبی) خودشان دیتای ادغام‌شده‌ی همه‌ی فایل‌های این پوشه را محاسبه می‌کنند.

## آپلود از رابط کاربری
به‌جای ریختن دستی در پوشه، می‌توانید در صفحه‌ی «فیدبک تماس» روی کارت «پوشه اکسل‌ها»
فایل‌ها را با درگ‌اند‌دراپ یا انتخاب چندفایلی مستقیم وارد کنید — نتیجه یکسان است.

## وضعیت و بازخوانی
صفحه‌ی «فیدبک تماس» ↔ کارت «پوشه اکسل‌های فیدبک» → لیست فایل‌های همگام‌شده با تعداد ردیف هرکدام را نشان می‌دهد.
برای بازخوانی بی‌درنگ (بدون صبر ۱۵ ثانیه‌ای)، دکمه‌ی «بازخوانی پوشه هم‌اکنون» را بزنید.

> ماشینِ محاسبه دقیقاً همان منطق پنل دستیار فیدبک QC است؛ ردلاین با هر شکل ذخیره
> (عدد، رشته‌ی کوتیشن‌دار) درست خوانده می‌شود و تاریخ‌های عددی Excel به شمسی تبدیل می‌شوند.
